## 🐛 문제 해결

### 문제: 주민번호 매칭 실패
**원인**: 주민번호 형식 불일치
**해결**: 하이픈 제거 및 공백 제거 확인

### 문제: 금액 불일치
**원인**: 숫자 형식 차이 (쉼표, 문자열)
**해결**: `numberify()` 함수 사용

### 문제: 메모 저장 실패
**원인**: JSON 형식 오류
**해결**: `JSON.stringify()` 사용

### 문제: 월지급계산 오류
**원인**: 급여데이터 시트 참조 오류
**해결**: 컬럼 인덱스 재확인 (B→1, C→2, G→6, R→17)
