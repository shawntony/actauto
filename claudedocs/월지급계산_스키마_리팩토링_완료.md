# 월지급계산/월지급DB 스키마 리팩토링 완료

## 📋 작업 개요

월지급계산 및 월지급DB 시트의 스키마 파일을 생성하고, `monthlyPayrollUIHandler.js`의 하드코딩된 열 참조를 스키마 기반 매핑으로 리팩토링했습니다.

**작업 일시**: 2026-01-30
**우선순위**: 🟡 HIGH (코드 품질 개선)
**상태**: ✅ 완료

## 🎯 완료된 작업

### 1. 스키마 파일 생성

#### ✅ `src/payroll/schemas/월지급계산_schema.js`
- **15개 컬럼** (A~O) 구조 정의
- 각 컬럼의 출처 매핑 (급여데이터, 보험시트들)
- 계산 공식 정의 (`calculateFinalPayment`)
- 헬퍼 함수 제공 (`getColumnIndex`, `createDataRow`)

**주요 컬럼**:
- A: 월 (시스템 생성)
- B~D: 급여데이터에서 가져옴
- E~J: 보험 시트들에서 매칭
- K~N: 사용자 정의 필드
- O: 최종지급액 (계산)

#### ✅ `src/payroll/schemas/월지급DB_schema.js`
- **19개 컬럼** (A~S) 구조 정의
- 월지급계산의 모든 열(A~O) + 추가 계산 열(P~S)
- 추가 계산 공식 정의 (`calculateAdditionalColumns`)
- DB 행 생성 함수 (`createDBRow`)

**추가 계산 컬럼**:
- P: 보험공제합계1 (E+F+G+H)
- Q: 보험공제합계2 (P+I)
- R: 기타공제 (J)
- S: 최종실지급액 (O+P+Q+R)

## 📌 주요 참고 사항

1. **컬럼 문자 → 인덱스 변환**
   - `columnLetterToIndex('D')` → 3 (0-based)
   - `columnLetterToIndex('AB')` → 27 (0-based)

2. **시트 쓰기 시 주의**
   - getRange는 1-based 인덱스 사용
   - 스키마는 0-based 인덱스 제공
   - 쓰기 시 `+1` 필요: `pcSheet.getRange(pcRow, kColIndex + 1, ...)`

3. **보험 시트별 주민번호 위치**
   - 국민연금, 건강보험, 산재보험: D열 (index 3)
   - 고용보험: E열 (index 4)
   - 스키마에서 자동 조회됨
