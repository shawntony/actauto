## ⚠️ 발견된 문제점

### 1. 컬럼 매핑 오류

**기존 코드 (잘못된 매핑)**:
```javascript
basicSalary: row[8] || 0,  // ❌ 실제는 월근무시간
bonus: row[9] || 0,  // ❌ 실제는 기본급
mealAllowance: row[10] || 0,  // ❌ 실제는 직책수당
positionAllowance: row[11] || 0,  // ❌ 실제는 식대수당
```

**수정된 코드 (올바른 매핑)**:
```javascript
basicSalary: row[9] || 0,  // ✅ J열: 기본급
bonus: 0,  // ⚠️ 급여데이터에 없음
positionAllowance: row[10] || 0,  // ✅ K열: 직책수당
mealAllowance: row[11] || 0,  // ✅ L열: 식대수당
```

### 2. 상여 항목 누락

**문제**: 급여데이터 시트에 **상여 컬럼이 존재하지 않음**

**영향**:
- 월지급계산 스키마에는 E열(상여)이 있음
- 급여데이터에서는 가져올 수 없음

**해결 방안**:
```javascript
bonus: 0,  // 기본값 0, 월지급계산 시트에서 직접 입력 필요
```

**권장 사항**:
- 옵션 1: 급여데이터 시트에 상여 컬럼 추가 (J열과 K열 사이에 삽입)
- 옵션 2: 월지급계산 UI에서 상여 금액 직접 입력 기능 추가
- 옵션 3: 상여는 별도 시트에서 관리하고 월지급계산에서만 반영

### 3. 직원 정보 필드 누락

**문제**: 월지급더존업로드에 필요한 부서/직급/직종 정보가 급여데이터에 없음

**급여데이터에 있는 것**:
- D열: 근무위치 (본사/지점)
- E열: 근무조

**월지급더존업로드에 필요한 것**:
- C열: 부서
- D열: 직급
- E열: 직종

**임시 해결책** (현재 적용):
```javascript
department: employeeData.workplace || '',  // 근무위치를 부서로 사용
position: '',  // 비워둠
jobType: employeeData.workShift || ''  // 근무조를 직종으로 사용
```

**권장 사항**:
- 급여기본정보 시트에 부서/직급/직종 컬럼 추가
- getEmployeeDataFromPayroll 함수에서 급여기본정보 시트도 조회하도록 수정
