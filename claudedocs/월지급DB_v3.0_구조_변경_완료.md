# 월지급DB v3.0 구조 변경 완료

## 📋 작업 일자
2026-01-31

## 🎯 변경 개요

### v2.3 → v3.0 주요 변경사항
- **컬럼 수**: 30개 (A~AD) → **32개 (A~AF)**
- **구조**: 선택적 복사 → **월급여더존다운로드 전체 복사**
- **설계 철학**: 계산 및 변환 → **원본 데이터 보존**

## 📊 실제 시트 구조 (검증 완료)

### 월지급DB 실제 헤더 (스크린샷 기준):
```
A: 급여기준월
B: 사원코드       ← v2에서 누락됨
C: 사원명
D: 부서           ← v2에서 누락됨
E: 직급           ← v2에서 누락됨
F: 직종           ← v2에서 누락됨
G: 기본급
H: 상여
... (급여 및 공제 항목)
AB: 차인지급액
AC: 입금처리여부
AD: 은행
AE: 계좌번호
AF: 예금주        ← v2에서 누락됨
```

### 구조 분석
```
월지급DB (32개 컬럼)
= A열 (급여기준월 - 시스템 생성)
+ B~AB열 (월급여더존다운로드 A~AA 전체 복사)
+ AC~AF열 (입금 관리 정보)
```

// 기타 공제

### 2. convertDazoneToPayrollDB() 재설계

**변경 사항**:
- 30개 컬럼 → **32개 컬럼** 생성
- 선택적 매핑 → **전체 복사** 방식
- 계산 로직 제거 → **더존 계산값 그대로 사용**

**매핑 구조**:
```javascript
const row = new Array(32).fill('');

// A: 시스템 생성
row[0] = new Date(month);

// B~AB: 더존 A~AA 전체 복사 (26개)
row[1] = dazoneRow.employeeCode;
row[2] = dazoneRow.name;
row[3] = dazoneRow.department;
... (전체 26개 필드)
row[27] = dazoneRow.netPay;

// AC~AF: 입금 관리 (4개)
row[28] = '대기';                    // AC: 입금처리여부
row[29] = bankInfo.bank;             // AD: 은행
row[30] = bankInfo.accountNumber;    // AE: 계좌번호
row[31] = dazoneRow.name;            // AF: 예금주
```

## 💡 v3.0 설계 원칙

### 1. 데이터 무손실
- 월급여더존다운로드의 **모든 컬럼** 보존
- 원본 데이터 **1:1 복사**
- 정보 손실 **0%**

### 2. 계산 단순화
- 더존에서 계산된 값 **그대로 사용**
- 재계산 로직 **제거** → 오류 가능성 제거
- 검증 용이성 **향상**

### 3. 추적 가능성
- 사원코드로 **직원 고유 식별**
- 부서/직급/직종으로 **조직 정보 추적**
- 원본 데이터와 **1:1 대응**으로 검증 가능

### 4. 확장성
- 더존 다운로드 형식 변경 시 **자동 반영**
- 추가 컬럼 **쉽게 확장** 가능
- 입금 관리 정보 **독립적** 추가

## 📝 테스트 시나리오

### 1. 기본 저장 테스트
```
1. 월급여더존다운로드에 샘플 데이터 1건 입력
2. 메뉴5: 월지급DB 저장 실행
3. 월지급DB 시트 확인:
   ✓ A열 = 급여기준월 (YYYY-MM-DD 말일)
   ✓ B열 = 더존.A(사원코드)
   ✓ C열 = 더존.B(사원명)
   ✓ D열 = 더존.C(부서)
   ✓ G열 = 더존.F(기본급) - 숫자 값
   ✓ P열 = 더존.O(지급액계)
   ✓ AB열 = 더존.AA(차인지급액)
   ✓ AC열 = "대기"
   ✓ AD~AE열 = 급여데이터에서 조회한 은행정보
   ✓ AF열 = C열(사원명)과 동일
```

### 2. 데이터 일치성 검증
```
월급여더존다운로드 A열 = 월지급DB B열 (사원코드)
월급여더존다운로드 B열 = 월지급DB C열 (사원명)
월급여더존다운로드 F열 = 월지급DB G열 (기본급)
월급여더존다운로드 O열 = 월지급DB P열 (지급액계)
월급여더존다운로드 AA열 = 월지급DB AB열 (차인지급액)
```

### 3. 계산 검증
```
더존 다운로드에서 계산된 값 그대로 사용:
- 지급액계 (P열) = 더존에서 계산된 값
- 공제액계 (AA열) = 더존에서 계산된 값
- 차인지급액 (AB열) = 더존에서 계산된 값

⚠️ 시스템에서 재계산하지 않음!
```
