# 급여데이터 스키마 업데이트 완료 보고서

## 📅 업데이트 일시
2026-01-30

## 🎯 업데이트 목적
Google Sheets "급여데이터" 시트의 실제 구조(31개 컬럼)를 정확히 반영하여 스키마 문서 업데이트

## ✅ 완료된 변경 사항

### 1. 시트 개요 업데이트
**변경 전**:
```markdown
- **시트명**: 급여데이터
- **용도**: 직원별 급여 정보 관리 및 급여 계산
- **데이터 소스**: 인사데이터 시트에서 기본 정보 연동
```

**변경 후**:
```markdown
- **시트명**: 급여데이터
- **스프레드시트**: 법인재무관리_해림씨앤피
- **컬럼 수**: 31개 (A-AE)
- **용도**: 직원별 급여 정보 관리 및 급여 계산
- **데이터 소스**: 인사데이터 시트에서 기본 정보 연동
```

### 2. 컬럼 구조 업데이트 (29개 → 31개)

#### 추가된 컬럼 (2개)
1. **AD열 (메모)**: 급여 관련 메모 필드
   - 데이터 타입: 텍스트
   - 용도: 급여 관련 특이사항 기록

2. **AE열 (통상임금)**: 통상임금 계산 결과
   - 데이터 타입: 숫자
   - 용도: 법정 통상임금 계산 결과 저장

#### 수정된 컬럼명
1. **T열**: "직종코드" → "적용월"
   - 이유: 실제 Google Sheets 표기와 일치 (기존 문서가 잘못 기록됨)

2. **P열**: "공휴일근로수당" → "공휴일특근수당"
   - 이유: 실제 시트 표기와 정확히 일치

3. **AA열**: "실_공휴일근로수당" → "실_공휴일특근수당"
   - 이유: P열과 일관성 유지

#### 추가된 비고 정보
- **K열 (직책수당)**: "앞에 공백 있음" 명시
- **N열 (연차수당)**: "앞에 공백 있음" 명시

### 3. 인덱스 참조 업데이트

**변경 전 (29개)**:
```javascript
const 컬럼매핑 = {
  // ... (중략)
  공휴일근로수당: 15,   // P열
  // ... (중략)
  직종코드: 19,         // T열
  // ... (중략)
  실_공휴일근로수당: 26, // AA열
  실_월지급액: 27,      // AB열
  '1주근로시간': 28     // AC열 ★ 4대보험신고 사용
};
```

**변경 후 (31개)**:
```javascript
const 컬럼매핑 = {
  // ... (중략)
  공휴일특근수당: 15,   // P열 (기존: 공휴일근로수당)
  // ... (중략)
  적용월: 19,           // T열 (기존: 직종코드 - 수정)
  // ... (중략)
  실_공휴일특근수당: 26, // AA열 (기존: 실_공휴일근로수당)
  실_월지급액: 27,      // AB열
  '1주근로시간': 28,    // AC열 ★ 4대보험신고 사용
  메모: 29,             // AD열 ★ 새로 추가
  통상임금: 30          // AE열 ★ 새로 추가
};
```

### 4. 데이터 무결성 주의사항 추가

**기존 (4개)**:
1. 주민등록번호: 민감정보로 보안 주의 필요
2. 계약시작일: Date 객체 또는 "YYYY.MM.DD" 형식 문자열
3. 월보수 (S열): 4대보험 기준 금액으로 정확성 중요
4. 1주근로시간 (AC열): 법정 근로시간 범위 검증 필요

**추가된 항목 (3개)**:
5. **적용월 (T열)**: 급여 적용 기준 월 (기존 직종코드 아님)
6. **메모 (AD열)**: 급여 관련 특이사항 기록
7. **통상임금 (AE열)**: 법정 통상임금 계산 결과

### 5. 계산 로직 추가

**기존**:
- R열 (합계금액): J~Q열 수당의 합계
- AB열 (실_월지급액): W~AA열 실지급 수당의 합계
- 실지급액: 기준액 - (미근무시간 × 시급) 반영

**추가**:
- **AE열 (통상임금)**: 통상임금 계산 (기본급 + 고정수당)
