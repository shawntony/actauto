## 🔄 월지급계산 매칭 로직 변경

### 변경 전: 이름 기반 매칭 (V7)

**매칭 키:**
```
A열(월) + "|" + B열(이름)
예: "2026-01-31|홍길동"
```

**문제점:**
- 동명이인 구분 불가
- 이름 오타 시 매칭 실패
- 고유 식별자가 아님

---

### 변경 후: 주민번호 앞 6자리 매칭 (V8)

**매칭 키:**
```
A열(월) + "|" + D열 앞 6자리(주민번호)
예: "2026-01-31|901225"
```

**장점:**
- ✅ 고유 식별자 사용
- ✅ 동명이인 문제 해결
- ✅ 오타 영향 최소화
- ✅ 데이터 정확성 향상

**주민번호 앞 6자리 형식:**
- YYMMDD (생년월일)
- 예시: "901225" = 1990년 12월 25일생 또는 2090년 12월 25일생
