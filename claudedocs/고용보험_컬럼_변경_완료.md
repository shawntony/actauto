# 고용보험 직원고용보험료 컬럼 변경 완료

## 📋 변경 요약

고용보험 시트의 직원고용보험료 컬럼을 **K열**에서 **X열**로 변경했습니다.

**변경일**: 2026-01-30
**변경 이유**: 실제 고용보험 시트의 직원고용보험료가 X열에 위치함

---

## 🔄 변경 사항

### 변경 전
```javascript
고용보험: {
  DATA_COLUMNS: {
    EMPLOYEE_INSURANCE: 'K',  // 11번째 컬럼 (인덱스 10)
    EMPLOYER_INSURANCE: 'Z'   // 26번째 컬럼 (인덱스 25)
  }
}
```

### 변경 후
```javascript
고용보험: {
  DATA_COLUMNS: {
    EMPLOYEE_INSURANCE: 'X',  // 24번째 컬럼 (인덱스 23)
    EMPLOYER_INSURANCE: 'Z'   // 26번째 컬럼 (인덱스 25)
  }
}
```

## 📊 고용보험 시트 최종 구조

| 열 | 인덱스 | 컬럼명 | 용도 |
|----|--------|--------|------|
| A | 0 | 월 | 매칭 키 (YYYY-MM-DD) |
| D | 3 | 근로자명 | 참고용 |
| **E** | 4 | **주민번호** | **매칭 키** ⚠️ (고용보험만 E열!) |
| **X** | 23 | **직원고용보험료** | **데이터 추출** (변경됨!) |
| Z | 25 | 사업주고용보험료 | 데이터 추출 |

---

## ⚠️ 중요 참고사항

### 1. 고용보험의 특수성
- **주민번호 컬럼**: E열 (다른 보험은 D열)
- **직원고용보험료**: X열 (변경됨!)
- **사업주고용보험료**: Z열 (변경 없음)

### 2. 컬럼 인덱스
- E열 = 5번째 컬럼 = 인덱스 4
- X열 = 24번째 컬럼 = 인덱스 23 ✅ **변경됨!**
- Z열 = 26번째 컬럼 = 인덱스 25

### 3. 매칭 로직
```
월(A열, YYYY-MM-DD) + 주민번호(E열, 앞 6자리) → 복합 키 생성
↓
고용보험 시트에서 매칭
↓
X열(직원고용보험료), Z열(사업주고용보험료) 값 추출
```

### 방법 1: 자동 테스트 스크립트

3. `testInsuranceMatching` 함수 실행
4. 로그에서 고용보험 매칭 결과 확인:
   ```
   [고용보험]
   ✅ 매칭 성공!
      매칭 키: 2026-01-31|901225
      직원고용보험료: 15000  (X열 값)
      사업주고용보험료: 25000 (Z열 값)
   ```

### 방법 2: UI 직접 테스트
1. 스프레드시트에서 월지급계산 UI 열기
2. 월: "2026-01" 입력
3. 직원 선택 후 처리
4. 월지급계산 시트에서 O열(고용보험료) 확인
   - X열의 값이 정상적으로 표시되어야 함

### 방법 3: 고용보험 시트 직접 확인
1. 고용보험 시트 열기
2. 테스트 데이터 확인:
   ```
   A열: 2026-01-31
   E열: 901225-1234567 (주민번호)
   X열: 15000 (직원고용보험료) ← 이 값이 추출됨
   Z열: 25000 (사업주고용보험료)
   ```
