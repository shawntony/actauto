# 월지급계산 - 급여데이터와 보험 데이터 매칭 방법

## 📋 개요

월지급계산 처리 시 급여데이터와 4대보험(국민연금, 건강보험, 고용보험, 산재보험) 데이터를 결합하는 방법을 설명합니다.

## 🔑 매칭 키 구성

### 1. 복합 키 (Composite Key)
보험 데이터 매칭은 2개의 키를 조합하여 수행합니다:

```
매칭 키 = 월(A열) + 주민번호 앞 6자리
```

### 2. 월 (Month) - A열
- **입력 형식**: `YYYY-MM` (예: `2026-01`)
- **변환 형식**: `YYYY-MM-DD` (해당 월의 말일)
- **예시**:
  - `2026-01` → `2026-01-31`
  - `2026-02` → `2026-02-28`
  - `2026-03` → `2026-03-31`

**변환 함수**: `convertToLastDayOfMonth(monthString)`
```javascript
function convertToLastDayOfMonth(monthString) {
  const [year, month] = monthString.split('-').map(num => parseInt(num, 10));
  const nextMonth = new Date(year, month, 1);
  const lastDay = new Date(nextMonth - 1);
  return Utilities.formatDate(lastDay, 'Asia/Seoul', 'yyyy-MM-dd');
}
```

### 3. 주민번호 앞 6자리 - D열 또는 E열
- **추출 대상**: 주민등록번호 앞 6자리 (생년월일 YYMMDD)
- **전처리**: 하이픈(-), 공백 제거
- **예시**:
  - `901225-1234567` → `901225`
  - `850315-2******` → `850315`

**추출 함수**: `extractResidentIdKey(residentId)`
```javascript
function extractResidentIdKey(residentId) {
  if (!residentId) return '';
  const cleaned = String(residentId).replace(/[-\s]/g, '');
  return cleaned.substring(0, 6);
}
```

## 📊 보험 시트별 매칭 컬럼

| 구분 | 컬럼 | 설명 | 예시 |
|------|------|------|------|
| 매칭 키 1 | A열 | 월 (YYYY-MM-DD) | `2026-01-31` |

## 🛠️ 핵심 함수

### 1. findInsuranceValue (단일 값 추출)
```javascript
/**
 * 보험 시트에서 단일 값 찾기 (국민연금, 산재보험)
 * @param {Sheet} sheet - 보험 시트
 * @param {string} month - 매칭할 월 (YYYY-MM-DD)
 * @param {string} idKey - 주민번호 앞 6자리
 * @param {Object} schema - 보험 시트 스키마
 * @returns {number} 보험료 금액
 */
function findInsuranceValue(sheet, month, idKey, schema) {
  // 1. 스키마에서 주민번호 컬럼 위치 가져오기
  const idColIndex = columnLetterToIndex(schema.MATCHING_COLUMNS.RESIDENT_ID);

  // 2. 스키마에서 데이터 컬럼 위치 가져오기
  const dataCol = Object.values(schema.DATA_COLUMNS)[0];
  const dataColIndex = columnLetterToIndex(dataCol);

  // 3. 시트에서 데이터 읽기
  const data = sheet.getRange(2, 1, lastRow - 1, maxCol).getValues();

  // 4. 매칭 조건으로 행 찾기
  for (const row of data) {
    const monthValue = String(row[0]).trim();  // A열
    const rowIdKey = extractResidentIdKey(String(row[idColIndex]));

    if (monthValue === month && rowIdKey === idKey) {
      return row[dataColIndex] || 0;  // 데이터 컬럼 값 반환
    }
  }

  return 0;  // 매칭 실패 시 0 반환
}
```

### 2. findInsuranceValues (여러 값 추출)
```javascript
/**
 * 보험 시트에서 여러 값 찾기 (건강보험, 고용보험)
 * @param {Sheet} sheet - 보험 시트
 * @param {string} month - 매칭할 월 (YYYY-MM-DD)
 * @param {string} idKey - 주민번호 앞 6자리
 * @param {Object} schema - 보험 시트 스키마
 * @returns {Object} 보험료 데이터 객체
 */
function findInsuranceValues(sheet, month, idKey, schema) {
  // 1. 스키마에서 주민번호 컬럼 위치 가져오기
  const idColIndex = columnLetterToIndex(schema.MATCHING_COLUMNS.RESIDENT_ID);

  // 2. 스키마에서 모든 데이터 컬럼 위치 가져오기
  const dataColumns = schema.DATA_COLUMNS;
  const dataColIndices = {};
  for (const [key, col] of Object.entries(dataColumns)) {
    dataColIndices[key] = columnLetterToIndex(col);
  }

  // 3. 시트에서 데이터 읽기
  const data = sheet.getRange(2, 1, lastRow - 1, maxCol + 1).getValues();

  // 4. 매칭 조건으로 행 찾기
  for (const row of data) {
    const monthValue = String(row[0]).trim();  // A열
    const rowIdKey = extractResidentIdKey(String(row[idColIndex]));

    if (monthValue === month && rowIdKey === idKey) {
      // 모든 데이터 컬럼 값 추출
      const result = {};
      for (const [key, colIndex] of Object.entries(dataColIndices)) {
        result[key] = row[colIndex] || 0;
      }
      return result;
    }
  }

  return {};  // 매칭 실패 시 빈 객체 반환
}
```

## ⚠️ 주의사항

### 1. 주민번호 컬럼 위치 차이
- **국민연금, 건강보험, 산재보험**: D열
- **고용보험**: E열 (유일한 예외!)

### 2. 월 형식 변환 필수
- 사용자 입력: `YYYY-MM` (예: `2026-01`)
- 보험 시트 A열: `YYYY-MM-DD` (예: `2026-01-31`)
- 반드시 `convertToLastDayOfMonth()` 함수로 변환 후 매칭

### 3. 주민번호 전처리
- 하이픈(-), 공백 제거 필수
- 앞 6자리만 추출하여 비교
- 대소문자 구분 없음

### 4. 매칭 실패 시 기본값
- 단일 값 함수 (`findInsuranceValue`): `0` 반환
- 여러 값 함수 (`findInsuranceValues`): `{}` 빈 객체 반환

### 5. 데이터 컬럼 위치
- **국민연금**: I열 (9번째)
- **건강보험**: O열 (15번째), AB열 (28번째)
- **고용보험**: X열 (24번째), Z열 (26번째)
- **산재보험**: O열 (15번째)
