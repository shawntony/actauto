- 체크박스를 통한 다중 선택 기능

### 2. 이름 검색 및 필터 ✅

## 🔧 기술 구현 세부사항

### UI 구조

```
┌─ 월 선택 섹션
│  └─ 드롭다운 (과거 6개월 ~ 미래 3개월)
│
├─ 사람 선택 섹션
│  ├─ 검색 및 필터 컨테이너
│  │  ├─ 이름 검색 입력창
│  │  ├─ 재직/퇴사 필터 드롭다운
│  │  └─ 매칭상태 필터 드롭다운
│  │
│  ├─ 전체 선택 체크박스
│  │  └─ 통계 표시 (재직: X명, 퇴사: Y명)
│  │
│  └─ 사람 목록 (스크롤 가능, 최대 500px)
│     └─ 각 인원별 체크박스 + 정보
│        ├─ 이름
│        ├─ 재직/퇴사 상태
│        ├─ 입사일
│        └─ 보험 매칭 상태 (✓ or ⚠️)
│
├─ 요약 섹션
│  ├─ 선택된 인원 수
│  ├─ 재직/퇴사 인원 수
│  ├─ 매칭 가능/불가 인원 수
│  └─ 중복 처리 경고 (해당 시)
│
└─ 버튼 컨테이너
   ├─ 취소 버튼
   └─ 실행 버튼 (선택 인원수 표시)
```

```

   ├─ F열: 계약시작일

   ↓
4. 각 인원별 보험 매칭 상태 확인
   ├─ 국민연금 시트 조회
   ├─ 건강보험 시트 조회
   └─ 고용보험 시트 조회
   ↓
5. UI에 데이터 렌더링
   ↓
6. 사용자 월 선택 시
   ↓
7. checkDuplicateProcessing() 호출
   ↓
8. 월지급계산 시트에서 중복 확인
   ↓
9. 중복 인원 강조 표시
   ↓
10. 사용자 실행 버튼 클릭
    ↓
11. 중복/매칭불가 확인 다이얼로그
    ↓
12. 순차 처리 시작
    ├─ 진행 상황 UI 표시
    ├─ 각 인원별 처리
    │  ├─ executeMonthlyPayrollForPerson() 호출
    │  ├─ 급여데이터에서 정보 읽기
    │  ├─ 보험 데이터 매칭
    │  ├─ 계산 수행
    │  ├─ 월지급계산 시트 업데이트

    └─ 실패 인원 및 오류
```

### 보험 매칭 로직

```javascript
// 주민번호 앞 6자리 기준 매칭
const idKey = residentId.substring(0, 6);  // YYMMDD
const compositeKey = month + '|' + idKey;  // 예: "2026-01|990101"

// 각 보험 시트에서 조회
if (국민연금.has(compositeKey)) → 매칭 가능
if (건강보험.has(compositeKey)) → 매칭 가능
if (고용보험.has(compositeKey)) → 매칭 가능

// 하나라도 매칭되면 'ok', 모두 매칭 안되면 'error'
```

### 중복 처리 확인 로직

```javascript
// 월지급계산 시트의 A열(월)과 B열(이름) 조회
const processedNames = new Set();

월지급계산.forEach(row => {
  if (row[0].includes(targetMonth)) {
    processedNames.add(row[1]);  // 해당 월에 처리된 이름 저장
  }
});

// 급여데이터의 이름과 비교
급여데이터.forEach((row, index) => {
  if (processedNames.has(row.name)) {
    duplicates.push(index);  // 중복 인덱스 저장
  }
});
```

## 🔒 보안 고려사항

### 주민번호 처리
- 주민번호는 앞 6자리만 사용 (YYMMDD)
- 전체 주민번호는 매칭 키 생성에만 사용
- UI에는 주민번호 표시 안 함 (필요 시 마스킹 고려)

### 데이터 검증
- 월 형식 검증 (YYYY-MM)
- 주민번호 길이 검증 (최소 6자리)
- 선택 인원 수 검증 (최소 1명)

### 오류 처리
- 시트 존재 여부 확인
- 데이터 로드 실패 시 사용자에게 알림
- 각 인원 처리 중 오류 발생 시에도 계속 진행

## 📞 문제 해결

### UI가 표시되지 않는 경우
1. 배포가 완료되었는지 확인
2. 브라우저 캐시 삭제 후 재시도
3. Google Apps Script 권한 확인

### 데이터가 로드되지 않는 경우
1. 급여데이터 시트 존재 여부 확인
2. 시트 이름 정확성 확인
3. 데이터 형식 확인 (B, C, F, G, R열)

### 보험 매칭 상태가 부정확한 경우
1. 보험 시트 데이터 확인
2. 주민번호 형식 확인 (숫자만)
3. 월 형식 확인 (YYYY-MM)

### 처리 중 오류 발생 시
1. 오류 메시지 확인
2. 해당 인원의 데이터 확인
3. 보험 데이터 존재 여부 확인
