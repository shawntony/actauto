## 🐛 문제 해결

### UI가 표시되지 않는 경우

**증상**: 메뉴 클릭 시 모달이 나타나지 않음

**해결 방법**:
1. 브라우저 콘솔 확인 (F12 → Console 탭)
2. 배포가 완료되었는지 확인
   ```bash
   npm run deploy
   ```
3. 브라우저 캐시 삭제
   - Chrome: Ctrl+Shift+Delete → 캐시된 이미지 및 파일 삭제
4. 시트 닫고 다시 열기

### 데이터가 로드되지 않는 경우

**증상**: 사람 목록이 비어있음

**해결 방법**:
1. 브라우저 콘솔에서 오류 메시지 확인
2. Google Apps Script 로그 확인
   - 도구 → 스크립트 편집기
   - 실행 → 실행 로그 보기
3. 급여데이터 시트 확인
   - B열: 근무자명 있는지 확인
   - C열: 주민번호 있는지 확인

### 보험 매칭 상태가 모두 ⚠️인 경우

**증상**: 모든 인원이 매칭 불가로 표시됨

**해결 방법**:
1. 보험 시트 데이터 확인
   - 국민연금, 건강보험, 고용보험 시트에 데이터가 있는지
2. 월 형식 확인
   - A열이 "YYYY-MM" 형식인지 (예: "2026-01")
3. 주민번호 형식 확인
   - 숫자만 있는지, 하이픈 등 특수문자 처리 확인

### 처리 중 오류 발생

**증상**: 일부 인원 처리 중 오류 발생

**해결 방법**:
1. 오류 메시지 확인
2. 해당 인원의 데이터 확인
   - 급여데이터 시트에서 해당 행 확인
   - 모든 필수 열에 데이터가 있는지 확인
3. 보험 데이터 확인
   - 해당 월의 보험 데이터가 있는지 확인

### 권한 오류

**증상**: "권한이 없습니다" 또는 "승인 필요" 메시지

**해결 방법**:
1. Google Apps Script 권한 승인
   - 도구 → 스크립트 편집기
   - 실행 → 함수 실행 → matchAllPayrollData_V6
   - 권한 검토 → 계정 선택 → 허용
2. 브라우저에서 팝업 차단 해제
3. 시트 소유자 또는 편집 권한 확인

```bash
git reset --hard HEAD
```

### 수동 복원

1. `src/payroll/72. 월지급계산 처리.js` 파일의 54-81행을 원래대로 복원:

```javascript
// 원래 코드 (54-81행)
  if (!targetMonth) {
    const response = ui.prompt(
      '월지급계산 처리 - 월 입력',
      '처리할 월을 입력하세요 (예: 2026-01):',
      ui.ButtonSet.OK_CANCEL
    );

    if (response.getSelectedButton() !== ui.Button.OK) {
      ui.alert('취소되었습니다.');
      return;
    }

    targetMonth = response.getResponseText().trim();

    if (!targetMonth) {
      ui.alert('월을 입력해주세요.');
      return;
    }

    if (!/^\d{4}-\d{2}$/.test(targetMonth)) {
      ui.alert('올바른 형식으로 입력해주세요. (예: 2026-01)');
      return;
    }

    // ✅ A열 업데이트 (해당 시트만)
    updateSheetMonthColumn(pcSheet, targetMonth, PAYMENT_CALC_SHEET);
  }
```

2. 새로 생성한 파일 삭제:
```bash
rm src/payroll/html/monthlyPayrollUI.html
rm src/payroll/monthlyPayrollUIHandler.js
```

3. 다시 배포:
```bash
npm run deploy
```
