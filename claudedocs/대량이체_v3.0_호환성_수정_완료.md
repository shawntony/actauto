# 대량이체 v3.0 호환성 수정 완료

## 📋 작업 일자
2026-01-31

## 🔍 발견된 문제

### 증상
1. **대량이체 메뉴 실행 시 "해당 월에 데이터가 없습니다" 오류**
2. **입금처리여부가 "완료"로 표시됨** (사용자 요구: "처리"로 표시)

### 근본 원인
`bulkTransferHandler.js`가 **v2.3 컬럼 인덱스**를 사용하고 있었음:
- **v2.3**: 30개 컬럼 (A~AD), B열 = 이름
- **v3.0**: 32개 컬럼 (A~AF), B열 = 사원코드, C열 = 사원명

## ✅ 수정 내용

### 파일: `src/payroll/bulkTransferHandler.js`

#### 1. readPayrollDBByMonth() 인덱스 수정 (lines 109-119)

**수정 전 (v2.3 인덱스)**:
```javascript
const data = filteredData.map((row, index) => {
  return {
    rowIndex: index,
    name: String(row[1] || '').trim(),        // B: 이름 ❌ v3는 사원코드
    netPay: Number(row[23]) || 0,             // X: 차인지급액 ❌ v3는 AB(27)
    bank: String(row[28] || '').trim(),       // AC: 은행 ❌ v3는 AD(29)
    accountNumber: String(row[29] || '').trim(), // AD: 계좌번호 ❌ v3는 AE(30)
    hasBank: Boolean(row[28] && row[29])
  };
});
```

**수정 후 (v3.0 인덱스)**:
```javascript
const data = filteredData.map((row, index) => {
  return {
    rowIndex: index,
    name: String(row[2] || '').trim(),        // C: 사원명 ✅
    netPay: Number(row[27]) || 0,             // AB: 차인지급액 ✅
    bank: String(row[29] || '').trim(),       // AD: 은행 ✅
    accountNumber: String(row[30] || '').trim(), // AE: 계좌번호 ✅
    hasBank: Boolean(row[29] && row[30])

```

#### 2. updatePaymentStatus() 수정 (lines 268-304)

**변경 사항**:
1. **기본 상태값 변경**: `status = '완료'` → `status = '처리'`
2. **AC열 인덱스 수정**: `getRange(rowNumber, 28)` → `getRange(rowNumber, 29)`
3. **이름 읽기 인덱스 수정**: `row[1]` → `row[2]`

**수정 전**:
```javascript
function updatePaymentStatus(month, processedNames, status = '완료') {
  ...
  data.forEach((row, index) => {
    const dateStr = formatDateToString(row[0]); // A: 급여기준월
    const name = String(row[1] || '').trim();   // B: 이름 ❌

    if (dateStr.startsWith(month) && processedNames.includes(name)) {
      const rowNumber = index + 2;
      dbSheet.getRange(rowNumber, 28).setValue(status); // AB열 (27+1) ❌
      updatedCount++;
    }
  });
}
```

**수정 후**:
```javascript
function updatePaymentStatus(month, processedNames, status = '처리') {
  ...
  data.forEach((row, index) => {
    const dateStr = formatDateToString(row[0]); // A: 급여기준월
    const name = String(row[2] || '').trim();   // C: 사원명 ✅

    if (dateStr.startsWith(month) && processedNames.includes(name)) {
      const rowNumber = index + 2;
      dbSheet.getRange(rowNumber, 29).setValue(status); // AC열 (28+1) ✅
      updatedCount++;
    }
  });
}
```

## 📊 v2.3 vs v3.0 컬럼 매핑 비교

| 데이터 항목 | v2.3 구조 | v3.0 구조 | 인덱스 변경 |
|------------|-----------|-----------|-------------|
| 급여기준월 | A(0) | A(0) | 변경 없음 |
| 사원코드 | ❌ 없음 | B(1) | **신규 추가** |
| 사원명 | B(1) | C(2) | **+1** |
| 차인지급액 | X(23) | AB(27) | **+4** |
| 입금처리여부 | AB(27) | AC(28) | **+1** |
| 은행 | AC(28) | AD(29) | **+1** |
| 계좌번호 | AD(29) | AE(30) | **+1** |
| 예금주 | ❌ 없음 | AF(31) | **신규 추가** |

## 🧪 테스트 시나리오

### 1. 대량이체 데이터 조회 테스트
```
1. 월지급DB에 2026-01 데이터가 있는지 확인
2. 메뉴 > 대량이체 등록 선택
3. 월 선택 드롭다운에서 "2026-01" 선택
4. 데이터 목록 확인:
   ✓ 사원명이 올바르게 표시되는가?
   ✓ 차인지급액이 올바른 금액인가?
   ✓ 은행명이 정확한가?
   ✓ 계좌번호가 올바른가?
```

### 2. 대량이체 등록 및 상태 업데이트 테스트
```
1. 위 테스트에서 표시된 데이터 중 일부 선택
2. "대량이체 등록" 버튼 클릭
3. 대량이체 시트 확인:
   ✓ 선택한 데이터가 정상적으로 추가되었는가?
   ✓ 입금통장표시가 "YYYY-MM급여" 형식인가?
4. 월지급DB 시트 확인:
   ✓ 해당 직원들의 AC열이 "처리"로 변경되었는가?
   ✓ "완료"가 아닌 "처리"로 표시되는가?
```

### 3. 데이터 일치성 검증
```
월지급DB 확인:
- C열 (사원명) = 대량이체에 표시된 예금주
- AB열 (차인지급액) = 대량이체에 표시된 입금액
- AD열 (은행) = 대량이체에 표시된 은행
- AE열 (계좌번호) = 대량이체에 표시된 계좌번호
- AC열 (입금처리여부) = "처리"
```
