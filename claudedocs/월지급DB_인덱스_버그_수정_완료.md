## 🔍 발견된 문제

### 심각한 인덱스 오류
`savePayrollDB.js`의 `readDazoneDownloadData()` 함수가 **잘못된 컬럼을 읽고 있었습니다**.

#### 증상
- 모든 급여 항목이 **1칸씩 밀려서** 읽힘
- row[4] → 코드는 "기본급"이라고 생각, 실제는 "직종" (문자열!)
- row[5] → 코드는 "상여"라고 생각, 실제는 "기본급"

### 영향 범위
- ❌ **잘못 저장된 데이터**: 기본급에 직종 값이 저장됨
- ❌ **계산 오류**: 총급여, 세후지급액 등 모두 오류
- ❌ **입금 처리 오류**: 잘못된 금액으로 입금 시도 가능성

### 2. 실제 시트 구조 (검증 완료)

월급여더존다운로드 시트 실제 헤더:
```
A(0):  사원코드
B(1):  사원명
C(2):  부서
D(3):  직급
E(4):  직종
F(5):  기본급        ← row[5]
G(6):  상여          ← row[6]
H(7):  식대수당      ← row[7]
I(8):  직책수당      ← row[8]
J(9):  연장근로수당  ← row[9]
K(10): 연차수당      ← row[10]
L(11): 야간수당      ← row[11]
M(12): 공휴일특근수당 ← row[12]
N(13): 기타수당      ← row[13]
O(14): 지급액계      ← row[14] (총급여)
P(15): 국민연금      ← row[15]
Q(16): 건강보험      ← row[16]
R(17): 고용보험      ← row[17]
S(18): 장기요양보험료 ← row[18]
T(19): 소득세        ← row[19]
U(20): 지방소득세    ← row[20]
V(21): 연말정산소득세
W(22): 연말정산지방소득세
X(23): 연말정산선불특
Y(24): 학자금상환액
Z(25): 공제액계
AA(26): 차인지급액   ← row[26] (세후지급액)
```

**문제**: 월급여더존다운로드 시트에 해당 컬럼이 없음

**현재 대응**:
- Q열 (사업주추가고용보험료): 0 저장
- R열 (산재보험료): 0 저장

**영향**:
- Y열 (사업주부담１) = 0
- Z열 (산재보험료2) = 0
- AA열 (총비용) = C열 (총급여)와 동일 (사업주 부담 미포함)

**해결 방안** (향후 선택 필요):
1. **Option A**: 보험 시트에서 별도 조회
   - 장점: 정확한 보험료 반영
   - 단점: 복잡도 증가

2. **Option B**: 더존 다운로드 시트에 컬럼 추가
   - 장점: 단일 출처 유지
   - 단점: 더존 다운로드 형식 변경 필요

3. **Option C**: 월지급계산 시트 데이터 활용
   - 장점: 기존 데이터 활용
   - 단점: 이중 관리

## 🧪 테스트 권장사항

### 1. 기존 데이터 검증
```javascript
// 기존에 저장된 데이터가 있다면 확인 필요
// 월지급DB 시트에서 샘플 데이터 확인:
// - D열(기본급)에 숫자가 아닌 값이 있는가?
// - 급여 금액이 비정상적으로 작거나 큰가?
```

### 2. 신규 저장 테스트
1. 월급여더존다운로드에 테스트 데이터 입력
2. 메뉴5: 월지급DB 저장 실행
3. 저장된 데이터 확인:
   - B열(이름) = 더존.B(사원명) ✅
   - D열(기본급) = 더존.F(기본급) ✅
   - C열(총급여) = 더존.O(지급액계) ✅
   - W열(세후지급액) = 더존.AA(차인지급액) ✅

### 3. 계산 검증
```
총비용(AA열) = 총급여(C열) + 사업주부담(Q열) + 산재보험(R열)
현재: AA = C + 0 + 0 = C
```
