### 기존 계산식 (v1.0)
```
최종지급액 = D(총급여) - E - F - G - H - K - L - M - N

```

### 새로운 계산식 (v2.0)

#### 1. 총급여 계산 (C열)
```
총급여 = 기본급 + 상여 + 식대수당 + 직책수당 + 연장근로수당 + 연차수당 + 야간수당 + 공휴일특근수당 + 기타수당

C = D + E + F + G + H + I + J + K + L
```

#### 2. 세후지급액 계산 (W열)
```
세후지급액 = 총급여 - 국민연금 - 건강보험료 - 고용보험료 - 장기요양보험료 - 소득세 - 지방소득세

W = C - M - N - O - P - S - T
```

**참고**: Q(사업주고용보험), R(산재보험), U~V(연말정산)는 실지급액 계산에서 제외
