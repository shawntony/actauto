# Menu 5 (월지급DB 저장) 테스트 가이드

## 📋 테스트 개요

**목적**: 월지급DB 저장 기능이 정상적으로 작동하는지 검증
**소요 시간**: 약 10-15분
**필요 파일**: `src/payroll/test_savePayrollDB.js`

---

## 🚀 테스트 준비

### 1. 테스트 스크립트 확인

테스트 스크립트가 생성되었습니다:
```
src/payroll/test_savePayrollDB.js
```

이 스크립트는 다음 기능을 제공합니다:
- ✅ 샘플 데이터 자동 생성 (3명의 직원)
- ✅ 저장 전후 상태 확인
- ✅ 결과 자동 검증
- ✅ 중복 체크 테스트
- ✅ 테스트 데이터 정리

### 2. Google Apps Script 편집기 열기

1. Google Sheets에서 프로젝트 열기
2. **확장 프로그램** → **Apps Script** 클릭
3. 좌측 파일 목록에서 `src/payroll/test_savePayrollDB.js` 찾기

## 🐛 문제 해결

### 문제 1: "시트를 찾을 수 없습니다"

**원인**: 월급여더존다운로드 시트가 없음
**해결**: `createSampleDazoneData()` 실행

### 문제 2: "은행 정보를 조회할 수 없습니다"

**원인**: 급여데이터 시트에 직원 정보 없음
**해결**: 급여데이터 시트에 홍길동, 김철수, 이영희 추가

### 문제 3: "저장 버튼이 활성화되지 않습니다"

**원인**: 직원을 선택하지 않음
**해결**: 체크박스를 클릭하여 직원 선택

### 문제 4: "컬럼 인덱스 오류"

**원인**: 월급여더존다운로드 시트 구조가 예상과 다름
**해결**: 스키마 파일 확인 및 `savePayrollDB.js` 컬럼 인덱스 수정

### 문제 5: "중복이 감지되지 않습니다"

**원인**: 날짜 형식 불일치
**해결**: 급여기준월을 정확히 "YYYY-MM-DD" 형식으로 입력
