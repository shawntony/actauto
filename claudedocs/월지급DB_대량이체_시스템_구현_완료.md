## ⚠️ 주의사항 및 알려진 이슈

### 1. 월급여더존다운로드 시트 구조 확인 필요
- **현재 상태**: 스키마는 예상 구조로 작성됨
- **필요 작업**: 실제 더존 다운로드 파일 구조 확인 후 스키마 업데이트
- **영향 범위**: `savePayrollDB.js`의 컬럼 인덱스 수정 필요 가능성
- **확인 방법**: 스키마 파일에 포함된 `checkDazoneDownloadStructure()` 함수 실행

### 2. 급여데이터 시트의 은행/계좌 컬럼 위치
- **현재 구현**: 마지막 2개 컬럼으로 가정
- **필요 작업**: 급여데이터 스키마 확인 후 정확한 컬럼 위치로 수정
- **영향 파일**: `savePayrollDB.js` → `getEmployeeBankInfo()` 함수

### 3. 대량이체 시트 생성
- **최초 실행 시**: 시트가 없으면 자동 생성됨
- **헤더 설정**: 자동으로 8개 컬럼 헤더 추가
- **권장**: 첫 실행 전 시트를 수동으로 생성하여 서식 지정 가능

### 4. 입금처리여부 필드
- **현재 구현**: 월지급DB 저장 시 "대기"로 자동 설정
- **수동 업데이트**: 입금 완료 후 수동으로 "완료"로 변경 필요
- **향후 개선**: 대량이체 완료 후 자동 업데이트 기능 추가 가능

### 월지급DB 저장 사용법
1. 더존 스마트A에서 월급여 다운로드
2. 월급여더존다운로드 시트에 복사/붙여넣기
3. 급여 관리 → 5. 월지급DB 저장
